Reading the keymap

Tap, hold, or switch

LT keys tap one keycode and activate a layer while held. MO activates a layer while held; TO switches the active layer.

Transparent bindings show the key inherited from the base layer. The preview models the selected layer over the default layer, not multiple simultaneously held layers.

This viewer never writes to GitHub or the keyboard. Firmware must be built and flashed separately. Key positions follow the keyboard's physical layout configuration.
